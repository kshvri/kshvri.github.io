# وب‌سایت شخصی علی کشوری

یک وب‌سایت شخصی واکنش‌گرا با HTML و CSS برای انتشار در GitHub Pages.

## فایل‌ها
- `index.html` — محتوای صفحه و لینک‌های پروفایل
- `style.css` — طراحی، رنگ‌ها و چیدمان واکنش‌گرا

## اجرای محلی
فایل `index.html` را با مرورگر باز کنید.

## شخصی‌سازی
متن معرفی و لینک‌ها در `index.html` قرار دارند؛ ظاهر صفحه را می‌توانید از `style.css` تغییر دهید.
